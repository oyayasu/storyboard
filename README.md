# Storyboard Studio Next v0.3.11 — Windows 10/11 + macOS

O aplicativo mantém o código original Tauri 2 / Rust + JavaScript da versão 0.3.11.

- **Windows 10/11 x64:** veja **[README_WINDOWS10.md](README_WINDOWS10.md)** para compilar o instalador NSIS `.exe` no GitHub Actions.
- **macOS:** execute `Build macOS App.command` com os requisitos Rust/Tauri/Xcode Command Line Tools já instalados.

`src-tauri/Cargo.lock` está incluído. O repositório não inclui dados/projetos de usuários; exporte os arquivos `.storyboardstudio` separadamente.
